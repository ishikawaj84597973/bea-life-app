# 駄菓子屋BAR Bea Life 公式Webアプリ

スマートフォン対応の日本語Webアプリです。ホーム、お知らせ、店舗情報、昼の駄菓子屋、夜のBAR、イベント、クーポンの7画面があります。

## 起動

Node.js 20.19以上または22.12以上を使用します。この環境では24.19で検証しています。

```sh
cd /workspace/bea-life-app
npm ci
npm run dev
```

Vite・標準JavaScript・CSSを使用。データベースやAPIキーは不要です。内容は `src/main.js`、デザインは `src/style.css` で編集できます。

## ビルド・テスト

```sh
npm run build
npm run preview
npm test
```

このクラウド環境では既存の `/usr/bin/chromium` を自動で使います。自分のPCでブラウザが未導入の場合は、テスト前に `npx playwright install chromium` を実行してください。

公開用ファイルは `dist/` に生成されます。静的サイト対応のホスティングに配信できます。テストではスマートフォン・PC表示、7画面、画面移動、お知らせ絞り込み、クーポンの保存・使用・キャンセル・リセット、横スクロールを検証します。

## 公開前の準備

住所、営業時間、定休日、電話、メニュー・価格、実際のお知らせ、イベント日程、クーポン特典・有効期限を確認して更新してください。未確認情報は「確認中」、お知らせ・イベント・クーポンはサンプルと明記しています。

クーポンは体験用で実店舗では使えません。状態はブラウザのlocalStorageに保存され、別端末とは共有されません。ブラウザのデータ削除やリセットで初期化できます。実際の特典に使うには、認証・サーバー側の利用記録・スタッフによる確認などが必要です。

管理画面・オンライン予約・決済・プッシュ通知は含まれていません。内容はファイル編集で更新します。

## クラウド環境での表示について

`npm start` で開発サーバーを起動できます（0.0.0.0、5173番ポート）。環境の再起動・復元時はサーバーを再起動する必要があります。

このオンボーディング画面はWebプレビューに対応していません。package.jsonの変更だけでは「次で開く」にブラウザの選択肢を追加できません。実際のスマートフォンから利用するには、`npm run build` で作成する `dist/` を静的サイトのホスティングサービスに公開してください。

## GitHub Pagesで無料公開

`.github/workflows/deploy-pages.yml` が main へのプッシュ時に公開用ビルドを自動配信します。GitHubのリポジトリで Settings → Pages → Build and deployment → Source を **GitHub Actions** に設定してください。設定後、Actions の「Publish Bea Life to GitHub Pages」から Run workflow を実行できます。

公開が成功すると通常 `https://ishikawaj84597973.github.io/bea-life-app/` で表示できます。このURLは配信完了まで利用できません。無料のGitHub Pagesは公開リポジトリで利用可能です。非公開リポジトリの場合はプランを確認し、公開範囲の変更は慎重に判断してください。
